# Synthesis Handoff — 综合交付包生成器

将 RTL 源码 freeze 并打包交付给综合流程。

## 输入

- RTL 源目录
- 顶层模块名
- 时钟列表（名称、周期、时钟域）
- 复位类型（同步/异步、高有效/低有效）

## 输出

```
syn/<top>_<date>/
├── rtl/                     # RTL freeze 副本（只读）
│   ├── filelist.f           # 扁平文件列表
│   └── *.v / *.sv
├── <top>.sdc                # 基本时序约束模板
├── README.md                # 交付说明
└── version.txt              # 版本标识
```

## 输出规范

### 1. RTL freeze

- 从 `rtl/` 复制所有源码到 `syn/rtl/`
- 生成扁平 `filelist.f`（不含路径，仅文件名，供综合脚本使用）
- 确保文件列表不含 testbench 文件

```bash
# filelist.f 格式
<top_module>.v
<module_a>.v
<module_b>.v
# ...
```

### 2. SDC 时序约束初稿

```tcl
# <top>.sdc — 时序约束初稿
# Auto-generated by syn-handoff — 需综合工程师确认

# 时钟定义（按项目修改时钟名与周期）
create_clock -name clk_a -period 40.0 [get_ports CLK_A]
create_clock -name clk_b -period 20.0 [get_ports CLK_B]

# 时钟分组（异步时钟域）
set_clock_groups -asynchronous \
    -group [get_clocks {clk_a}] \
    -group [get_clocks {clk_b}]

# 输入延迟（按项目修改端口名）
set_input_delay  -clock clk_a -max 5.0 [get_ports DATA_IN]
set_input_delay  -clock clk_a -min 2.0 [get_ports DATA_IN]

# 输出延迟
set_output_delay -clock clk_b -max 5.0 [get_ports DATA_OUT]
```

### 3. 交付说明

```markdown
# Synthesis Handoff — <module>

- **日期**：<date>
- **顶层模块**：<top>
- **RTL 版本**：基于 git commit <hash> 或 timestamp
- **时钟**：<clk_a> <period> / <clk_b> <period>
- **复位**：<reset_type>

## 内容

- `rtl/` — RTL 源码（freeze 副本，请勿修改）
- `filelist.f` — 编译文件列表
- `<top>.sdc` — 时序约束初稿（需综合工程师确认）

## 注意事项

- 异步时钟域间的 CDC 路径已做时钟分组处理
- 所有模块已通过 lint 检查
```

## 设计约束

- 交付包以日期命名，防止覆盖（如 `syn/<top_module>_20260701/`）
- 输出到项目 `syn/` 目录下
- SDC 只生成初稿，标注 `需综合工程师确认`
- SDC 语法基于 Synopsys DC 工具链（如有其他综合工具，需调整语法）
