# RegMap Generator — 寄存器映射生成器

根据结构化寄存器定义，生成 RTL、TB、文档、脚本四端的寄存器映射文件，确保定义一致。

## 输入

- 寄存器定义 JSON（地址、位域、默认值、读写属性）
- 可选：是否生成 TB 宏定义 / 文档 / 脚本枚举

## 输出

| 文件 | 用途 | 是否可选 |
|:--|:--|:--:|
| `<module>_regmap.svh` | TB 地址宏 + 位域宏定义 | 推荐 |
| `<module>_regmap.md` | 寄存器表文档（Markdown） | 可选 |
| `<module>_regmap.py` / `.h` | 脚本/软件寄存器枚举 | 可选 |

```json

      "addr": "0x00",
      "reset": "0x0000_0000",
      "description": "Control register",
      "fields": [
        {"name": "EN",     "bits": "0",    "rw": "RW", "reset": "1'b0", "desc": "Module enable"},
        {"name": "MODE",   "bits": "2:1",  "rw": "RW", "reset": "2'b0", "desc": "Operation mode"},
        {"name": "RSVD",   "bits": "31:3", "rw": "RO", "reset": "29'h0","desc": "Reserved"}
      ]
    },
    {
      "name": "CFG",
      "addr": "0x04",
      "reset": "0x0000_00A0",
      "description": "Configuration register",
      "fields": [
        {"name": "THRESHOLD","bits": "7:0",  "rw": "RW", "reset": "8'hA0","desc": "Threshold value"},
        {"name": "RSVD",    "bits": "31:8", "rw": "RO", "reset": "24'h0","desc": "Reserved"}
      ]
    },
    {
      "name": "STAT",
      "addr": "0x08",
      "reset": "0x0000_0000",
      "description": "Status register",
      "fields": [
        {"name": "BUSY",   "bits": "0",    "rw": "RO", "reset": "1'b0", "desc": "Module busy"},
```

## 输出规范

### 1. TB 宏定义文件（`<module>_regmap.svh`）

```systemverilog
// Auto-generated by regmap-gen — DO NOT EDIT
// Module: <module>

// Address macros
`define CTRL        32'h00
`define CFG         32'h04
`define STAT        32'h08
`define DATA        32'h0C
`define FIFO        32'h10

// Field macros: CTRL
`define CTRL_EN         0
`define CTRL_MODE_L     1
`define CTRL_MODE_H     2

// Field width macros
`define CFG_THRESHOLD_W       8
```

### 2. 寄存器文档（`<module>_regmap.md`）

```markdown
# <module> 寄存器映射

| 地址 | 名称 | 描述 |
|------|------|------|
| 0x00 | CTRL | 控制寄存器 |
| 0x04 | CFG  | 配置寄存器 |
| 0x08 | STAT | 状态寄存器 |

### CTRL 0x00

| 位域 | 名称 | 读写 | 默认值 | 描述 |
|------|------|:--:|:------:|------|
| 0    | EN      | RW | 0 | Module enable |
| 2:1  | MODE    | RW | 0 | Operation mode |
| 31:3 | RSVD    | RO | 0 | Reserved |
```

## 设计约束

- 所有输出文件带 `// Auto-generated by regmap-gen — DO NOT EDIT` 标识
- 地址使用 `32'h` 格式，位域使用 `高位:低位` 格式
- `_regmap.svh` 文件存放于 `tb/<module>/` 目录，在 testbench 中通过 `` `include `` 使用
- 确认 testbench 包含路径正确（如存在 `tb/<module>/` 下的 .v 文件）

## Step N: 接入验证（生成后必须执行，防止孤儿文件）

> **痛点来源**：生成的 `_regmap.svh` 曾变孤儿——生成了、放对了位置、内容也对，
> 但没有任何 UVM 文件 `` `include `` 它，所有 sequence 仍用硬编码地址，regmap
> 形同虚设。生成 ≠ 启用，本步骤强制确认接入。

生成 `_regmap.svh` 后，逐项确认并报告：

| # | 检查项 | 方法 | 不通过处理 |
|:-:|:--|:--|:--|
| 1 | 至少一处 include | `grep -rn 'include.*<module>_regmap.svh' tb/` 非空 | 在 UVM pkg 或 base sequence 加 `` `include `` |
| 2 | filelist 有 +incdir+ | `grep '+incdir+<dir>' <uvm.flist> Makefile` 含 regmap 所在目录 | 在 uvm.flist + Makefile 编译命令加 `+incdir+tb` |
| 3 | 至少一处地址宏被引用 | `grep -rn '\`<MODULE>_' tb/uvm/sequence/` 非空 | 选最常用寄存器地址改宏做样板（如 `apb_read(\`<MODULE>_CTRL, rd)`） |
| 4 | 编译通过 | `make sim-uvm-compile`（或对应编译命令）PASS | 修复 include 路径/宏名 |
| 5 | 与 RTL 地址集一致 | consistency_check 4.6 通过 | 补 RTL 新增地址的宏 |

**接入验证报告**：
```
regmap 接入验证 — <module>
✅ include: tb/uvm/<module>_uvm_pkg.sv:<line>
✅ +incdir+: uvm.flist + Makefile sim-uvm-compile/-cov
✅ 宏引用: N 个 sequence 使用 `<MODULE>_*` 宏
✅ 编译: make sim-uvm-compile PASS
✅ 地址集: consistency_check 4.6 一致
→ regmap 已启用为单一真相源
```

任一项不通过 → 报告并修复，不允许"生成即结束"。
